# src/features — 피처 설계·조립

> 루트 [`CLAUDE.md`](../../CLAUDE.md)의 절대 규칙이 우선한다.

## 원칙: 키움 REST API로만 수급 가능한 피처만 사용

| 카테고리 | 피처 | 확보 방법 | 상태 |
|---|---|---|---|
| 가격/거래량 | OHLCV(수정주가), 거래대금 → **리턴으로 변환해 정상성 확보** | 일봉 TR (ka10081) | ✅ |
| 기술적 지표 | MA(5/20/60), MACD, RSI, Bollinger, ATR, CCI | OHLCV로부터 직접 계산 (API 의존 없음) | ✅ |
| 매크로 지표 | KOSPI/KOSDAQ 지수, 해외지수 ETF | 지수 TR (ka20006) + 국내상장 ETF 일봉 | 수집 ✅ / 결합 ⬜ |
| 수급 데이터 | 외국인/기관/개인 순매수 | 투자자별매매동향 TR (ka10059) | 수집 ✅ / 결합 ⬜ |
| 종목 고정 특성 | 업종, 시가총액 구간, 요일 임베딩 | ⚠️ 업종은 API에 없음 → `configs/config.yaml`에 직접 기입 | 부분 ⬜ |

## 절대 지킬 것: look-ahead 방지

- 모든 지표는 t 시점까지의 정보만 사용한다. `center=True`나 `shift(-n)`은
  `technical.py`에 **등장해서는 안 된다**
- 유일한 예외가 `forward_log_return()` — 이건 **라벨**이지 피처가 아니다.
  피처 목록에 절대 섞지 말 것
- 새 피처를 추가하면 `tests/test_technical.py::test_no_lookahead`가 검증한다
  (미래 종가를 3배로 조작해도 과거 지표값이 안 변하는지 확인)

## 스케일 정규화 규칙

가격 스케일 값을 그대로 쓰면 안 된다. "70,000원"은 시대에 따라 의미가 달라진다.

- MA → 종가 대비 괴리율 (`close / ma - 1`)
- MACD → 종가로 나눔
- ATR → 종가로 나눔 (ATR%)
- RSI, CCI → 0~1 스케일로 축소

## 데이터 정제

`drop_halted_days()` — 거래정지일 제거. **지표 계산 전에** 호출해야 rolling 창이 오염되지 않는다.

거래정지일은 `volume=0` + `open=high=low=close`(직전 종가) 형태로 온다.
남겨두면 가짜 0 수익률 → 변동성 과소추정 → ATR/RSI 왜곡으로 번진다.
실측: 8종목에서 61행 발견 (한미반도체 20, 삼성바이오 35, 삼성전자/NAVER 각 3).

## 다음 작업: `build.py`

종목 피처에 매크로 시퀀스와 static covariate를 결합해 크로스어텐션 입력을 만든다.

⚠️ **주의**: KODEX 미국반도체MV(390390)는 2021-06-30 상장이라 2015~2021 구간이 없다.
글로벌 시퀀스를 필수 입력으로 만들면 학습 구간이 5년으로 줄어든다 → 마스킹 처리할 것.

⚠️ PER/PBR은 조회 시점 스냅샷이라 과거 시계열이 아니다. t 시점 피처로 쓰면 look-ahead다.
static covariate로만 쓰거나, 시계열 TR을 따로 찾아야 한다.
